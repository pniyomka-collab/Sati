# 🪷 สมาธิ · Sati

แอปนั่งสมาธิแบบไฟล์เดียว — ตั้งเวลา · ระฆังเตือน · บันทึกผล · ระบบเกมสะสมแต้ม · คู่มืออานาปานสติ
รองรับภาษาไทยและอังกฤษ ปรับแต่งได้ทุกอย่าง

> A single-file Flask meditation timer with bells, journaling, gamification and an Anapanasati guide. Thai / English.

---

## 📦 ติดตั้งและรัน

ต้องมี **Python 3.9 ขึ้นไป** และไลบรารีเดียวคือ Flask

```bash
pip install flask
```

```bash
python app.py
```

แล้วเปิดเบราว์เซอร์ไปที่ **http://127.0.0.1:5000**

ครั้งแรกที่รัน โปรแกรมจะสร้างไฟล์ `meditation.db` (SQLite) ไว้ข้าง ๆ `app.py` โดยอัตโนมัติ — ข้อมูลทั้งหมดอยู่ในเครื่องคุณ ไม่ส่งออกไปไหน

### เปลี่ยนพอร์ต / ที่เก็บข้อมูล

| ตัวแปรสภาพแวดล้อม | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `PORT` | พอร์ตที่ใช้รัน | `5000` |
| `SATI_DB` | ตำแหน่งไฟล์ฐานข้อมูล | `meditation.db` ข้าง `app.py` |

```bash
PORT=8080 python app.py
```

ถ้าใช้ PowerShell บน Windows:

```bash
$env:PORT=8080; python app.py
```

## 🧘 วิธีใช้งาน

### 1. เริ่มนั่งสมาธิ (แท็บ “นั่งสมาธิ”)

1. **เลือกเวลา** — กดปุ่มด่วน (5 / 10 / 15 / 20 / 30 / 45 / 60) หรือลากสไลเดอร์ 1–120 นาที
   ติ๊ก **“ไม่จำกัดเวลา”** ถ้าอยากนั่งแบบเปิด แล้วค่อยกดจบเอง
2. **ตั้งตัวเลือกด่วน** (ถ้าต้องการ)
   - *เตรียมตัวก่อนเริ่ม* — หน่วงกี่วินาทีก่อนระฆังเริ่มดัง (ให้เวลาวางเครื่อง หลับตา จัดท่านั่ง)
   - *ระฆังเตือนทุก ๆ* — ระฆังกลางคาบทุก N นาที ใส่ `0` เพื่อปิด
   - *ช่วงแผ่เมตตาท้ายคาบ* — เวลาหลังระฆังจบ สำหรับแผ่เมตตา ใส่ `0` เพื่อปิด
3. **คำกล่าวนำ** — ติ๊กเปิด/ปิด และเลือกบทที่ต้องการ หรือ “สุ่มทุกครั้ง”
4. กด **“เริ่มนั่งสมาธิ”**

### 2. ระหว่างนั่ง

| สิ่งที่เห็น | ความหมาย |
|---|---|
| ป้ายมุมซ้ายบน | ช่วงปัจจุบัน — *เตรียมตัว → ภาวนา → แผ่เมตตา* |
| วงแหวน | ความคืบหน้าของคาบ |
| วงกลมเรืองแสง | ตัวนำลมหายใจ ขยาย = หายใจเข้า, หดลง = หายใจออก |
| ข้อความจาง ๆ ด้านล่าง | คำเตือนสติที่ขึ้นเป็นระยะ |

ปุ่มควบคุม: **+1 นาที** · **⏸ หยุดชั่วคราว** (กด `Spacebar` ก็ได้) · **จบ** (จบคาบก่อนเวลา)

> เปิด “ไม่ให้หน้าจอดับ” ไว้ในตั้งค่า จอจะไม่ดับระหว่างนั่ง (ใช้ได้กับ Chrome / Edge / Safari รุ่นใหม่)

### 3. หลังนั่งจบ

หน้าสรุปจะขึ้นมาพร้อม **คำชมให้กำลังใจ**, XP ที่ได้รับ, ระดับ, streak และเหรียญตราที่เพิ่งปลดล็อก
จากนั้นใส่ข้อมูลเพิ่มได้:

- **อารมณ์หลังนั่ง** 😖 😕 😐 🙂 😌
- **ให้ดาว** คุณภาพสมาธิ 1–5
- **โน้ตสั้น ๆ** ว่าวันนี้ใจเป็นอย่างไร

กด **“บันทึกผล”** เพื่อเก็บลงฐานข้อมูล หรือ **“ไม่บันทึก”** เพื่อทิ้งคาบนี้

> คาบที่สั้นกว่า 20 วินาทีจะไม่ถูกบันทึก

### 4. ดูย้อนหลัง

- **แท็บ “บันทึก”** — กราฟแท่ง 14 วันล่าสุด, รายการทุกคาบ (กด ✕ เพื่อลบทีละรายการ), ปุ่มดาวน์โหลด **CSV** และ **JSON**
- **แท็บ “ความก้าวหน้า”** — ระดับและแถบ XP, สถิติ 9 ช่อง, ปฏิทินความสม่ำเสมอ 18 สัปดาห์, เหรียญตรา 16 แบบ
- **แท็บ “เรียนรู้”** — คู่มืออานาปานสติ 7 บท และบทคำกล่าวนำทั้งหมด

## 🎮 ระบบเกม

**XP** = จำนวนนาทีที่นั่งสะสม + 5 แต้มต่อหนึ่งคาบ

**ระดับ** มี 10 ขั้น — ผู้เริ่มต้น → ผู้ตั้งใจ → ผู้ฝึกหัด → ผู้มีสติ → ผู้สงบ → ผู้ตั้งมั่น → ผู้รู้ลม → ผู้ปล่อยวาง → ผู้เบิกบาน → ผู้ตื่นรู้
(ระดับที่ 1 ใช้ 60 XP และเพิ่มขึ้นทีละ 40 XP ต่อระดับ)

**เหรียญตรา 16 แบบ** เช่น 🌱 ก้าวแรก · 🔥 ไฟติดแล้ว (3 วันติด) · 🎋 หนึ่งสัปดาห์ · ☀️ หนึ่งเดือนเต็ม · 🌅 อรุณรุ่ง (นั่งก่อน 7 โมง) · 🌙 ราตรีสงบ (หลัง 3 ทุ่ม) · 🗿 หนึ่งชั่วโมงรวด · ☯️ เช้า-เย็น · 📖 นักบันทึก

**Streak** นับจากวันที่มีการนั่งติดต่อกัน (นับจากวันนี้ย้อนหลัง ถ้าวันนี้ยังไม่ได้นั่งจะเริ่มนับจากเมื่อวาน)

## ⚙️ การตั้งค่า (แท็บ “ตั้งค่า”)

ทุกค่าบันทึกอัตโนมัติทันทีที่เปลี่ยน

| กลุ่ม | ปรับอะไรได้ |
|---|---|
| 🎨 **รูปลักษณ์** | ภาษา (ไทย/English), ธีมมืด-สว่าง, สีหลัก 8 สี, ขนาดตัวอักษร |
| ⏱ **เวลา** | ระยะเวลาเริ่มต้น, เวลาเตรียมตัว, ระฆังกลางคาบ, ช่วงแผ่เมตตา, นับขึ้น/ถอยหลัง, ไม่จำกัดเวลา, ปุ่มเวลาด่วน |
| 🔔 **เสียง** | เสียงระฆังเริ่ม/จบ/กลางคาบ (ขันระฆัง · กระดิ่ง · ฆ้อง · เกราะไม้ · เงียบ), จำนวนครั้งที่ตี, ระดับเสียง, เสียงบรรยากาศ (ฝน · คลื่นทะเล · ป่าไม้ · เสียงโอม) |
| 🪷 **ประสบการณ์** | เปิด/ปิดคำกล่าวนำและเลือกบท, คำชมตอนจบ, ถามอารมณ์, นาฬิกา, กันจอดับ, วงกลมนำลมหายใจ + วินาทีหายใจเข้า-ออก |
| 🎯 **เป้าหมาย** | เป้าหมายนาทีต่อวัน, จำนวนวันต่อสัปดาห์ |

### เพิ่มบทของตัวเอง

ในหัวข้อ **“บทของฉัน”** เลือกประเภท (คำกล่าวนำ / คำชม) ใส่ชื่อบทกับเนื้อความ แล้วกด **เพิ่ม**
บทที่เพิ่มเองจะเข้าไปอยู่ในรายการสุ่มและเลือกใช้ได้เหมือนบทที่มีมาให้

### ปุ่มจัดการข้อมูล

- **🔔 ทดสอบเสียงระฆัง** — ลองฟังเสียงที่เลือกไว้
- **คืนค่าตั้งต้น** — รีเซ็ตเฉพาะการตั้งค่า ไม่แตะประวัติการนั่ง
- **ลบข้อมูลทั้งหมด** — ลบประวัติการนั่งทุกคาบ (ย้อนกลับไม่ได้ — ควร export เก็บไว้ก่อน)

## 🛠 การแก้ไขเนื้อหาในโค้ด

เนื้อหาทั้งหมดอยู่ใน `app.py` เป็นลิสต์ของ dict แก้ได้ตรง ๆ แล้วรีสตาร์ตเซิร์ฟเวอร์

| ตัวแปร | บรรทัด | เนื้อหา |
|---|---|---|
| `DEFAULT_SETTINGS` | 91 | ค่าตั้งต้นทั้งหมดของแอป |
| `OPENINGS` | 162 | บทคำกล่าวนำ (`title_th/en`, `body_th/en`) |
| `PRAISE` | 210 | คำชมให้กำลังใจ (`th`, `en`) |
| `LESSONS` | 240 | บทเรียนอานาปานสติ (`icon`, `title_th/en`, `body_th/en`) |
| `REMINDERS` | 300 | คำเตือนสติที่ขึ้นระหว่างนั่ง |
| `LEVEL_TITLES` | 311 | ชื่อระดับทั้ง 10 ขั้น |
| `BADGES` | 324 | นิยามเหรียญตรา (เงื่อนไขปลดล็อกอยู่ในฟังก์ชัน `compute_stats()`) |
| `TXT` | ในส่วน `HTML_JS` | ข้อความ UI สองภาษา รูปแบบ `key:['ไทย','English']` |

โครงสร้างไฟล์: ฐานข้อมูล/การตั้งค่า → เนื้อหาธรรมะ → HTML 4 ท่อน (`HTML_HEAD`, `HTML_BODY`, `HTML_JS`, `HTML_JS2`) → สถิติและระบบเกม → REST API

## 🔌 REST API

| Method | Endpoint | ใช้ทำอะไร |
|---|---|---|
| `GET` | `/api/bootstrap` | ดึงการตั้งค่า + สถิติ + เนื้อหา + ประวัติ ทั้งหมดในครั้งเดียว |
| `POST` | `/api/settings` | บันทึกการตั้งค่า (ส่งเฉพาะคีย์ที่เปลี่ยน) |
| `POST` | `/api/settings/reset` | คืนค่าตั้งต้น |
| `POST` | `/api/session` | สร้างคาบใหม่ → คืน `id`, `stats`, `xp_gained`, `new_badges` |
| `PATCH` | `/api/session/<id>` | เพิ่มอารมณ์หลังนั่ง / ดาว / โน้ต |
| `DELETE` | `/api/session/<id>` | ลบคาบเดียว |
| `GET` `DELETE` | `/api/sessions` | ดึงประวัติ / ลบทั้งหมด |
| `POST` | `/api/content` | เพิ่มบทของตัวเอง (`kind` = `opening` หรือ `praise`) |
| `DELETE` | `/api/content/<id>` | ลบบทของตัวเอง |
| `GET` | `/api/export.csv` · `/api/export.json` | ดาวน์โหลดข้อมูลทั้งหมด |

## ❓ ปัญหาที่พบบ่อย

**ไม่ได้ยินเสียงระฆัง**
เบราว์เซอร์ต้องการให้ผู้ใช้กดปุ่มก่อนจึงจะเล่นเสียงได้ — เสียงจะปลดล็อกเองเมื่อกด “เริ่มนั่งสมาธิ” ลองกด **ทดสอบเสียงระฆัง** ในหน้าตั้งค่า และเช็กว่าระดับเสียงไม่ได้ถูกลากไปที่ 0

**หน้าเว็บขึ้นแต่ดูไม่สวย / ไม่มีสี**
Tailwind และฟอนต์โหลดจาก CDN — ต้องต่ออินเทอร์เน็ตอยู่ (ตัวแอปและข้อมูลทำงานออฟไลน์ได้ปกติ)

**จอดับระหว่างนั่ง**
เปิด “ไม่ให้หน้าจอดับ” ในตั้งค่า — บางเบราว์เซอร์ (โดยเฉพาะ iOS Safari รุ่นเก่า) ยังไม่รองรับ Wake Lock

**พอร์ต 5000 ถูกใช้อยู่แล้ว**
รันด้วยพอร์ตอื่น เช่น `PORT=8080 python app.py` (บน macOS พอร์ต 5000 มักถูก AirPlay ใช้อยู่)

**ย้ายข้อมูลไปเครื่องอื่น**
ก๊อปปี้ไฟล์ `meditation.db` ไปวางข้าง ๆ `app.py` บนเครื่องปลายทาง

**อยากเริ่มใหม่หมด**
ปิดเซิร์ฟเวอร์ ลบไฟล์ `meditation.db` แล้วรันใหม่

## 🔒 ความเป็นส่วนตัว

ทุกอย่างทำงานบนเครื่องคุณ — ข้อมูลการนั่งสมาธิเก็บใน SQLite ไฟล์เดียว ไม่มีบัญชีผู้ใช้ ไม่มีการส่งข้อมูลออก
